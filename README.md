# 🏦 Bank Management System

A simple and interactive Mini Bank Management System built using **HTML, CSS, JavaScript, and Node.js (Express)**.
This project simulates basic banking operations like account creation, deposit, withdrawal, and balance tracking.

---

## 🚀 Features

* 🧑 Create Account
* 💰 Deposit Money
* 💸 Withdraw Money
* 📊 Real-time Balance Update
* 🧾 Transaction Messages (instant feedback)
* ⚡ Fast and lightweight (no database required)

---

## 🛠️ Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Node.js, Express.js
* Storage: In-memory (Array)
